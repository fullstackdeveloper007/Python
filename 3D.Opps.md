## Oops (Class, Method Types, Inheritence..)


### Methods:
Python provides three types of methods: instance methods, static methods, and class methods.

**1. Instance Methods** : Instance methods are the most common type of methods in Python classes. They are associated with instances of a class and have access to both instance-specific data (attributes) and class-level data. Here’s an example of an instance method:

```python
class Dog:
    def __init__(self, name, breed):
        self.name = name
        self.breed = breed

    def bark(self):
        return f"{self.name} is barking!"

dog1 = Dog("pomeranian")
dog1.bark()  # Output: pomeranian is barking
```
🔑 Why `self`is required:
The attribute `self.name` belongs to the specific instance emp1. Without `dog1.self`, Python has no way of knowing that name is an instance variable.

#### Key Characteristics of Instance Methods

- **Access to Instance Data:**  
  Instance methods have access to instance-specific data through the `self` parameter. They can read and modify the attributes of the instance within these methods.

- **Access to Class Data:**  
  If necessary, instance methods can access class-level data through `self.__class__` attribute, allowing interaction with class-level attributes and methods.

- **Instance-Specific:**  
  Each instance of the class has its own copy of instance methods. When you call an instance method on an object, it operates on the data associated with that specific instance.

- **Common Use:**  
  Instance methods are the default choice for methods in Python classes. They are used for operations that depend on the state of a particular instance.

**2. Static Methods**
Static methods are defined using the `@staticmethod` decorator. They do not have access to the instance or class state and are not bound to either. Static methods behave like regular functions but are scoped within the class for organization. Here's an example:
```python
class MathUtils:
    @staticmethod
    def add(x, y):
        return x + y
```

- **No Access to Instance or Class Data:** Static methods do not have access to instance-specific or class-specific data. They are self-contained and behave like regular functions.
- **Self-Contained: **Static methods are not dependent on the state of an instance or class. They are isolated and operate independently.
- ** Organization:** They are often used for utility functions or methods that are closely related to a class but don’t require access to instance-specific data.

**3. Class Methods** Class methods are defined using the `@classmethod` decorator. They are bound to the class and can access and modify class-level attributes. Class methods take the class itself as their first argument, typically named cls. Here's an example:
```python
class MyClass:
    count = 0  # Class-level attribute

    def __init__(self, data):
        self.data = data
        MyClass.count += 1

    @classmethod
    def get_count(cls):
        return cls.count
```

**Key characteristics of class methods:**
- **Access to Class Data:** Class methods have access to class-level attributes and can modify them. They receive the class itself as their first argument, cls.
- Class-Level Operations: They are often used for operations that involve the class as a whole, such as modifying class-level attributes, creating alternative constructors, or implementing factory methods.
- Inherited Behavior: Class methods are inherited by subclasses, allowing for consistent behavior across subclasses.
