# Loops

### While loops
A while loop executes the body of the loop while a specified condition remains True

```python
# Syntax
while specified condition is True:
    body of loop 

Example:
multiplier = 1
result = multiplier * 5
while result <= 50:
    print(result)
    multiplier += 1
    result = multiplier * 5
print("Done")    
```

**break** - A break statement in Python provides a way to exit out of a loop before the loop's condition is false. Once a break statement is encountered, the program's control flow jumps out of the loop and continues executing the code after the loop.
**pass** - A pass statement in Python is a placeholder statement which is used when the syntax requires a statement, but you don't want to execute any code or command.

### for loops
for loops iterate over a sequence of elements, executing the body of the loop for each element in the sequence

**A. using range()**

```python
Syntax
for variable in sequence:

# Example 1

    print(number * 3)

# Example 2:
for x in range(7):
    if x % 2 == 0:
        print(x)

# The loop should print 0, 2, 4, 6

# As a list comprehension:
even_numbers = [x for x in range(7) if x % 2 == 0]
print(even_numbers)
```

**9. map()**

### 👉 Syntax:
```python
map(function, iterable)
```
* `function`: a function that takes one argument.
* `iterable`: list, tuple, set, etc.
* Returns: an **iterator** (use `list()` to see results).

### 👉 Example:

```python
numbers = [1, 2, 3, 4]
squares = map(lambda x: x**2, numbers)
print(list(squares))   # [1, 4, 9, 16]


# or (without lamda) Normal function to square a number
def square(x):
    return x ** 2

numbers = [1, 2, 3, 4]
squares = map(square, numbers)

print(list(squares))   # [1, 4, 9, 16]

```

**10. 🔹 `filter()`**

### 👉 Syntax:

```python
filter(function, iterable)
```

* `function`: returns **True/False** for each element.
* `iterable`: list, tuple, set, etc.
* Returns: an **iterator** (use `list()` to see results).

### 👉 Example:

```python
numbers = [10, 15, 20, 25, 30]
evens = filter(lambda x: x % 2 == 0, numbers)
print(list(evens))   # [10, 20, 30]


# (without lamda)  Normal function to check even numbers
def is_even(x):
    return x % 2 == 0

numbers = [10, 15, 20, 25, 30]
evens = filter(is_even, numbers)

print(list(evens))   # [10, 20, 30]

```

**11. `reduce()` (extra, part of functional programming)**

⚠️ `reduce()` is not built-in like map/filter. It comes from `functools`.

### 👉 Syntax:

```python
from functools import reduce
reduce(function, iterable[, initializer])
```

* `function`: takes two arguments.
* `iterable`: sequence of elements.
* `initializer` (optional): starting value.

### 👉 Example:

```python
from functools import reduce

numbers = [1, 2, 3, 4]
result = reduce(lambda a, b: a + b, numbers)
print(result)   # 10 (1+2+3+4)


from functools import reduce

#(reduce() without lambda) Normal function to add two numbers
def add(a, b):
    return a + b

numbers = [1, 2, 3, 4]
result = reduce(add, numbers)

print(result)   # 10

```

# 🔹 Quick Comparison

| Function   | Syntax                   | Purpose                              |
| ---------- | ------------------------ | ------------------------------------ |
| `map()`    | `map(func, iterable)`    | Transform each element               |
| `filter()` | `filter(func, iterable)` | Keep only elements where func → True |
| `reduce()` | `reduce(func, iterable)` | Combine elements into a single value |
