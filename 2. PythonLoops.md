# Loops

### 1. While loops
A while loop executes the body of the loop while a specified condition remains True

```python
# Syntax
while specified condition is True:
    body of loop 

Example:
multiplier = 1
result = multiplier * 5
while result <= 50:
    print(result)
    multiplier += 1
    result = multiplier * 5
print("Done")    
```

**break** - A break statement in Python provides a way to exit out of a loop before the loop's condition is false. Once a break statement is encountered, the program's control flow jumps out of the loop and continues executing the code after the loop.
**pass** - A pass statement in Python is a placeholder statement which is used when the syntax requires a statement, but you don't want to execute any code or command.

### 2.  for loops
for loops iterate over a sequence of elements, executing the body of the loop for each element in the sequence

**A. using range()**

```python
Syntax
for variable in sequence:

# Example 1
for number in range(1, 6+1, 2):
    print(number * 3)

# Example 2:
for x in range(7):
    if x % 2 == 0:
        print(x)

# The loop should print 0, 2, 4, 6

# As a list comprehension:
even_numbers = [x for x in range(7) if x % 2 == 0]
print(even_numbers)
```
**1. Iterating over a list**
```python
items = ['apple', 'banana', 'cherry']
for item in items:
    print(item)
```

**2. Iterating over a string**
```python
for char in "hello":
    print(char)
```

enumerate(iterable, start=0)

**Notes:** The enumerate() function in Python adds a counter to an iterable (like a list, tuple, or string) and returns it as an enumerated object. This allows you to loop through both the elements and their indices at the same time.

**6.Using dict.items() to iterate over dictionary key-value pairs**
```python

```
