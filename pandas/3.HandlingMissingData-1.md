# Pandas Missing Data Handling Part-1

This markdown file includes code examples and descriptions for handling missing data in Pandas. The following table summarizes each method used:

## 📋 Summary Table

| Operation                                   | Description                                                                                 |
|--------------------------------------------|---------------------------------------------------------------------------------------------|
| `read_csv(parse_dates)`                    | Reads CSV and parses the 'day' column as datetime.                                         |
| `type(df.temperature[0])`                  | Checks the data type of the first value in the temperature column.                         |
| `set_index('day')`                         | Sets the 'day' column as the DataFrame index.                                              |
| `fillna(0)`                                | Replaces all missing values with 0.                                                        |
| `fillna({ ... })`                          | Replaces missing values using a dictionary for different columns.                          |
| `fillna(method='ffill')`                   | Forward fills missing values from the previous valid observation.                          |
| `fillna(method='bfill')`                   | Backward fills missing values using the next valid observation.                            |
| `fillna(method='bfill', axis='columns')`   | Backward fills missing values column-wise.                                                 |
| `fillna(method='ffill', limit=1)`          | Forward fills only one consecutive missing value per column.                               |
| `interpolate()`                            | Fills missing values using linear interpolation.                                           |
| `dropna()`                                 | Drops all rows with at least one missing value.                                            |
| `dropna(how='all')`                        | Drops only rows where all values are missing.                                              |
| `dropna(thresh=2)`                         | Keeps rows with at least 2 non-null values, drops the rest.                                |

---

## 📄 Code and Explanations

```python
import pandas as pd

# Read CSV and parse 'day' as datetime
df = pd.read_csv("weather_data.csv", parse_dates=['day'])

# Check the type of the first value in the temperature column
type(df.temperature[0])

# Set the 'day' column as the index
df.set_index('day', inplace=True)

# Fill all missing values with 0
new_df = df.fillna(0)

# Fill missing values with specific values:
# - temperature with its mean
# - windspeed with its mean
# - event with a default value 'No Event'
new_df = df.fillna({
    'temperature': df.temperature.mean(),
    'windspeed': df.windspeed.mean(),
    'event': 'No Event'
})

# Forward fill: propagate last valid observation forward
new_df = df.fillna(method="ffill")

# Backward fill: propagate next valid observation backward
new_df = df.fillna(method="bfill")

# Backward fill along columns instead of rows
new_df = df.fillna(method="bfill", axis="columns")  # axis can be "index" or "columns"

# Forward fill but limit to 1 value per column
new_df = df.fillna(method="ffill", limit=1)

# Interpolate missing values (linear by default)
new_df = df.interpolate()

# Drop all rows that have any missing values
new_df = df.dropna()

# Drop only rows where all elements are missing
new_df = df.dropna(how='all')

# Keep only rows with at least 2 non-null values
new_df = df.dropna(thresh=2)
