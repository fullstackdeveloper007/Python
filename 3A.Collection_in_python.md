# Lists, tuple, Set, Dictionary , Range

## 1. List
A list is an ordered, mutable collection of items that can store `multiple data types (integers, strings, objects, etc.)` in a single variable. for example `my_list = [10, "hello", 3.14, True, [1, 2, 3]]
print(my_list)  # Output: [10, 'hello', 3.14, True, [1, 2, 3]]`. 

**Mutable-**  change the content after creation.
**ordered-** Elements have a fixed position (index), The order in which you insert elements is preserved.You can access items by their index (list[0], list[1], etc.).

* We can define a list like `my_list = []` or my_list = `list()`
* or directly assignment `my_list = [1, 2, 3, 4]`
* x = ["Now", "we", "are", "cooking!"]
*  integers are not iterable, they need to be converted to a range as below:
  ```python
for x in range(len(someList)):
    print(x)
```
### List common methods  
* list[index] = x - Replaces the element at index [n] with x.
* list.append(x) - Appends x to the end of the list.
* list.insert(index, x) - Inserts x at index position [index].
* list.pop(index) - Returns the element at [index] and removes it from the list. If [index] position is not in the list, the last element in the list is returned and removed.
* list.remove(x) - Removes the first occurrence of x in the list.
* list.sort() - Sorts the items in the list.
* list.reverse() - Reverses the order of items of the list.
* list.clear() - Deletes all items in the list.
* list.copy() - Creates a copy of the list.
* list.extend(other_list) - Appends all the elements of other_list at the end of list
* map(function, iterable) - Applies a given function to each item of an iterable (such as a list) and returns a map object with the results
* zip(*iterables) - Takes in iterables as arguments and returns an iterator that generates tuples, where the i-th tuple contains the i-th element from each of the argument iterables.


## 2. tuple 
A tuple is an ordered and immutable collection of elements. It is used to store multiple items in a single variable, just like lists, but the key difference is that tuples cannot be changed (immutable) after they are created.
* Defining a tuple
```python
1.Using Parentheses:
my_tuple = (1, 2, 3)
print(my_tuple)  # Output: (1, 2, 3)
2. Without Parentheses (Comma-Separated):
my_tuple = 1, 2, 3
print(my_tuple)  # Output: (1, 2, 3)
3.Single Element Tuple (with a comma):
single_element_tuple = (5,)
print(type(single_element_tuple))  # Output: <class 'tuple'>
4.Using tuple() Constructor:
my_tuple = tuple([1, 2, 3])
print(my_tuple)  # Output: (1, 2, 3)

`Multiple data types in one tuple
my_tuple = (1, "hello", 3.14, True, [5, 6], {"key": "value"})
print(my_tuple)

`Accessing Tuple Elements
my_tuple = (10, 20, 30)
print(my_tuple[0])  # Output: 10
```

### Use Cases of Tuples
* A. Returning multiple values from a function:
```python
def get_coordinates():
    return (10.5, 22.3)
* Immutable data collection: Tuples help protect the data from unintentional changes.
* Dictionary keys: Tuples can be used as keys since they are hashable, unlike lists.
x, y = get_coordinates()
print(x, y)  # Output: 10.5 22.3

my_dict = {
    (1, 2): "Point A",
    (3, 4): "Point B"
}
print(my_dict[(1, 2)])  # Output: Point A

```
* Q Fill in the blanks to complete the biography_list() function. This function reads in a list of tuples people, which contains the name, age, and profession of each person. Then, prints the sentence "__ is _ years old and works as __." 
For example, biography_list([("Ira", 30, "a Chef")]) should print: 
Ira is 30 years old and works as a Chef.

```python
def biography_list(people):
    # Iterate over each "person" in the given "people" list of tuples. 
    for person in people:

        # Separate the 3 items in each tuple into 3 variables: "name", "age", and "profession"
        name, age, profession = person

        # Format the required sentence and place the 3 variables in the correct placeholders using the .format() method
        print("{} is {} years old and works as {}.".format(name, age, profession))

# Call to the function
biography_list([("Ira", 30, "a Chef"), ("Raj", 35, "a Lawyer"), ("Maria", 25, "an Engineer")])
```

## 3.Set
- Unordered, unique values only (no duplicates).
- Useful for membership checks, removing duplicates.

```
nums = {1, 2, 3, 3}
print(nums)  # {1, 2, 3}

```

## 4. Dictionary

- Key-value pairs (mapping).
- Keys must be unique.

```
student = {"name": "Ali", "age": 22}
```

## 5. Range
```python
for i in range(5):  # 0,1,2,3,4
    print(i)

```
